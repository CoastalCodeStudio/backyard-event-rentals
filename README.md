# Tide & Timber — Backyard Event Rentals

A responsive, single-page practice website for a fictional backyard game and event rental company. It includes rental categories, sample packages and pricing, a stylized gallery, company story, and an interactive quote-request form.

## Preview locally

No build step or dependencies are required.

1. From this repository, start a local server:
   ```bash
   python3 -m http.server 8000
   ```
2. Open [http://localhost:8000](http://localhost:8000) in your browser.

You can also open `index.html` directly, though a local server provides the most reliable preview.

## Customize

- Update business details, package contents, and sample prices in `index.html`.
- Change the color palette and typography variables near the top of `styles.css`.
- Replace the CSS gallery illustrations with your own photos whenever they are ready.
- Connect the demo submit handler in `script.js` to your preferred form or email service before using the site publicly.
